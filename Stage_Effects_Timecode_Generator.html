Timecode Generator

Generates real SMPTE/EBU Linear Timecode (LTC) as an audio signal — the kind a hardware timecode box sends to lighting desks, video switchers, or multitrack recorders — using your browser's audio engine. Once started it rolls forward continuously from the start code below; it is not tied to any countdown. This is its own page so it can keep running independently and, in Chrome or Edge, send its output to one specific output of a multi-output sound card instead of your default speakers.
